Set up your support widget

Connect your DC, choose your colors, then download a configured index.html.

Open setup on an HTTPS origin allowed by your BlahDiem CDN. The default CDN allows *.blahim.com; custom builds can use a CDN configured for your own origin.

1. Connect your DC

The public profile must allow cross-origin requests. BlahDiem verifies it before the widget uses its connection details.

2. Application credentials

Use the app ID and hash from your DC's application settings. These public client credentials are separate from customer tokens.

3. Make it yours

Leave a field blank for the default. Colors accept CSS values such as #235347; radii use lengths such as 12px. For an image, use url("https://…").

4. Save and embed

Replace the release's index.html with your download. Keep it beside the same assets/ folder and serve over HTTPS. Your application supplies a customer token when it opens the widget.
